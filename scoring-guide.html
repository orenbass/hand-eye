שיטת הניקוד בכל המבחנים

המסמך מסביר כיצד נגזר הציון הגולמי (0-100) וכיצד הוא מומר לסקאלה הגלובלית (ברירת מחדל: 1–7).

תיאום עין-יד

  • 100% מתחלקים לאורך המסלול: קטעים בתוך המסלול מוסיפים נקודות, יציאה לקירות/חוץ גורעת.
  • המסלול מחושב באחוזים: inside, wall ו-outside. כל אחוז בקיר מוכפל במקדם קנס, ולחוץ קנס גבוה יותר.
  • הרמות עכבר מוסיפות קנס קבוע (liftFactor).
  • Raw = inside% − wallPenalty% − outsidePenalty% − liftPenalty%. ציון סופי בתחום 0–100 לאחר clamp.

הציון הסופי ממופה לטווח הגלובלי: scaled = min + (raw/100)·(max−min).

זמן תגובה

  • נספרות טעויות: לחיצות שגויות + מטרות שהוחמצו.
  • הפחתת נקודות פר טעימה: penaltyPerMistake = 100 / (expectedCycles · 1.1), כאשר expectedCycles משקלל אורך התבנית או משך בפועל.
  • Raw = clamp(100 − mistakesTotal · penaltyPerMistake, 0, 100).

הציון הסופי הוא Scale(raw). משך הופעת הצורה (shapeDisplaySec) משפיע על כמות המחזורי החישוב.

מעקב וקשב

  • TrackingScore = clamp(insideTime% − 2·exits, 0, 100).
  • ClickAccuracy = אחוז הקשות נכונות מתוך כלל הניסיונות (נכונות, שגיאות ופספוסים).
  • Raw = 0.5 · TrackingScore + 0.5 · ClickAccuracy.

משוקלל באופן שווה בין דיוק הנתיב לבין הקלדת הספרות.

ירי במטרות (Target ID)

  • Accuracy = hits / shots.
  • Penalty = wrongTargets · 0.12.
  • Raw = clamp((Accuracy − Penalty) · 100, 0, 100).

מציאת הצפון

  • נמדד שגיאת זווית בין הכיוון שסומן לבין כיוון הצפון האמיתי.
  • המרחק ביחס לרווח בין החצים (stepDeg) משייך את השגיאה לאחת מ-5 מדרגות.
  • כל מדרגה מייצרת יחס (1, 0.85, 0.7, 0.55, או חישוב לינארי עד 0.5) שממופה מיידית לסקאלה הגלובלית.

בקרת טיסה

  • מחושב המרחק הממוצע בין כלי הטיס למרכז המעגל.
  • ratio = max(0, 1 − avgDist / maxRadius).
  • Raw = clamp((ratio^2.2) · 100, 0, 100) – מדגיש דיוק גבוה.

מבחן הטסה

  • מתייחס לדגימת מסלול מלאה: התקדמות לאורך המסלול, שהייה בתוך המסדרון ודיוק ביחס למרכז.
  • PathCoverage – אחוז המסלול שכוסה.
  • InsideCoverage – כמה מההתקדמות בוצעה בתוך המסדרון (או fallback מתוך מדגם הנקודות).
  • CenterFactor – בודק עד כמה הנבחן צמוד למרכז (מקטין עד 20%).
  • Raw = clamp(PathCoverage · InsideCoverage · CenterFactor, 0, 1) · 100.

התמצאות וכיוונים

  • Raw = (מספר תשובות נכונות / מספר שאלות) · 100.
  • Scaled = min + (raw/100)·(max−min).

מיפוי הציון הגלובלי

כל המבחנים (מלבד מציאת הצפון שמחשבת ישירות) ממירים את הציון הגולמי (0–100) לטווח שהוגדר במסך ההגדרות הכללי.

  • scaleRange.min – ברירת מחדל 1.
  • scaleRange.max – ברירת מחדל 7.
  • Scaled = min + (raw/100) · (max − min).
